5. Logical Equivalences (p ≡ q)

Two statements are equivalent if they have the same truth value in every case. Prove with a truth table or by applying laws step by step (name the law each time!).

LawEquivalence
Identityp∧T ≡ p ; p∨F ≡ p
Dominationp∨T ≡ T ; p∧F ≡ F
Idempotentp∨p ≡ p ; p∧p ≡ p
Double negation¬(¬p) ≡ p
Commutative / Associativeorder and grouping don't matter (same operator)
Distributivep∧(q∨r) ≡ (p∧q)∨(p∧r) ; p∨(q∧r) ≡ (p∨q)∧(p∨r)

Contrapositivep → q ≡ ¬q → ¬p

Simplify ¬(p → q)

1. p→q ≡ ¬p ∨ q (implication law)

2. ¬(¬p ∨ q) (negate whole)

3. ¬(¬p) ∧ ¬q (De Morgan)

4. p ∧ ¬q (double negation) ¬(p→q) ≡ p ∧ ¬q

Show p → q ≡ ¬p ∨ q

Truth table: p→q = T,T,F,T for rows TT,TF,FT,FF. ¬p∨q gives the same T,T,F,T. ✓ Equivalent

6. Predicates & Quantifiers

Predicate P(x): a statement with variable x, e.g. P(x): "x > 3". Domain = values x may take.

SymbolRead asExample
∀x P(x)for every x∀x∈ℤ, x² ≥ 0
∃x P(x)there exists x∃x∈ℤ, x² = 9
∃!x P(x)exactly one x∃!x∈ℤ, x+1 = 4
¬(∀x P(x)) ≡ ∃x ¬P(x)   |   ¬(∃x P(x)) ≡ ∀x ¬P(x)

To negate: flip ∀ ↔ ∃ and negate the predicate.

Example

"Every student passed" → ∀x(Student(x) → Passed(x)).

Negation: ∃x(Student(x) ∧ ¬Passed(x)) = "at least one student did not pass".

NOT "every student failed"! One counterexample is enough.

Nested quantifiers — order matters!

StatementMeaning
∀x ∃y P(x,y)For each x some y (y may depend on x). Every student has a favourite book.
∃y ∀x P(x,y)ONE y works for all x. One book liked by everyone.
Negate ∀x ∃y P(x,y)

Flip first: ∃x ¬(∃y P(x,y)) → flip inner: ∃x ∀y ¬P(x,y).

¬(∀x∃y P) ≡ ∃x∀y ¬P

Common Mistake

Negation of "every x has some y" is NOT "every x has no y". It is "there is an x for which no y works".

Two Invalid Forms (Fallacies)

Affirming the consequent: p→q, q ∴ p ✗ (q may be true for another reason)

Denying the antecedent: p→q, ¬p ∴ ¬q ✗

Example: "If it rains, ground is wet. Ground is wet. So it rained." ✗ — a hose could have wet it.

  • Theorem – important proved statement; Lemma – helper result; Corollary – follows easily from a theorem; Conjecture – not yet proved.
  • For "if P then Q": P = hypothesis, Q = conclusion.
  • Testing examples can never prove a universal claim!

9. Proof Methods

(a) Direct Proof — assume P, derive Q

Square of an even integer is even

Let n be even, n = 2k. Then n² = 4k² = 2(2k²), and 2k² is an integer, so n² is even. ∎

(b) Contraposition — prove ¬Q → ¬P

If n² is even, then n is even

Contrapositive: if n is odd then n² is odd. n = 2k+1 ⇒ n² = 4k²+4k+1 = 2(2k²+2k)+1 → odd. ∎

(c) Vacuous & Trivial Proofs

TypeWhenExample
VacuousHypothesis P is always false ⇒ P→Q true"If n² < 0 then n is odd" (no integer has n²<0)
TrivialConclusion Q is always true"If n is even then n² ≥ 0"

(d) Contradiction — assume ¬S, reach an impossibility

√2 is irrational

Assume √2 = p/q in lowest terms. Then p² = 2q² ⇒ p² even ⇒ p even, p = 2k.

So 4k² = 2q² ⇒ q² = 2k² ⇒ q even. Both even — contradicts "lowest terms". ∎

(e) Proof by Cases

n² + n is even for every integer n

Case 1: n even, n = 2k ⇒ 4k²+2k = 2(2k²+k) even.

Case 2: n odd ⇒ n+1 even, and n²+n = n(n+1) has an even factor ⇒ even. ∎

(f) Proof of "iff" — prove BOTH directions

n even ⇔ n² even

(⇒) n = 2k ⇒ n² = 2(2k²) even.

(⇐) By contrapositive: n odd ⇒ n² odd (shown above). Both hold. ∎

10. Counterexamples

ONE counterexample disproves "for every x, P(x)".

False claimCounterexample
Every prime is odd2 is prime and even
If ab is even, both a and b are evena=2, b=3: ab=6 even, b odd
n² > n for every integer n>0n=1: 1² = 1, not greater
If a² = b² then a = ba=2, b=−2 (really a=b or a=−b)

11. Common Proof Mistakes

  • Using examples as proof of a universal statement.
  • Proving the converse instead of the original.
  • Circular reasoning (using what you want to prove).
  • Dividing by something that may be zero.
  • Direct proof: assuming the conclusion instead of the hypothesis.
  • Wrong quantifier negation.
  • Contradiction: forgetting to assume the negation, or stopping before a real contradiction.
  • "iff": giving only one direction.

Tips

Integer claims → try parity (even/odd), divisibility, cases. Real-number claims → inequalities, factorization. Plan backward but write forward.

UNIT II : Recurrence Relations

A recurrence relation defines each term using earlier terms. Initial conditions give the starting values.

1. Definition, Order, Solution

  • Order = largest gap between aₙ and a previous term used.
  • Solution = a sequence satisfying the recurrence AND the initial conditions.
RecurrenceOrderReason
aₙ = 2aₙ₋₁1only previous term
aₙ = aₙ₋₁ + aₙ₋₂2two previous terms
aₙ = 3aₙ₋₁ − aₙ₋₃3largest lag is 3
aₙ = aₙ₋₁² + 11 (nonlinear)squares the term

aₙ = 2aₙ₋₁ alone has many solutions; with a₀ = 3 we get 3, 6, 12, 24, …

2. Modelling

Define aₙ in words → choose index start → write update rule → state initial values → check first few terms.

Bacteria doubling every hour, a₀ = 50

aₙ = 2aₙ₋₁ (n≥1): 100, 200, 400… aₙ = 50·2ⁿ

Fibonacci sequence

F₀ = 0, F₁ = 1, Fₙ = Fₙ₋₁ + Fₙ₋₂ (n ≥ 2)

Terms: 0, 1, 1, 2, 3, 5, 8, 13, 21, …

Tower of Hanoi

Move n−1 disks away, move the biggest disk once, move the n−1 disks back on top.

T₀ = 0,   Tₙ = 2Tₙ₋₁ + 1  ⟹  Tₙ = 2ⁿ − 1

T₁=1, T₂=3, T₃=7, T₄=15.

aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ + … + cₖaₙ₋ₖ + f(n)

f(n) = 0 → homogeneous; f(n) ≠ 0 → non-homogeneous.

TypeExample

Method: Characteristic Equation

Try aₙ = rⁿ → get the characteristic equation → solve roots → write general solution → use initial conditions.

Distinct roots: aₙ − 5aₙ₋₁ + 6aₙ₋₂ = 0, a₀=1, a₁=4

r² − 5r + 6 = 0 ⇒ (r−2)(r−3)=0 ⇒ r = 2, 3.

aₙ = −2ⁿ + 2·3ⁿ

4. Non-homogeneous Recurrences

aₙ = aₙ⁽ʰ⁾ (homogeneous part) + aₙ⁽ᵖ⁾ (particular part)

Homogeneous part: solve with the forcing term set to 0. Particular part: any one solution of the full equation.

12

Shift operator & inverse operator

E(aₙ) = aₙ₊₁,   E²(aₙ) = aₙ₊₂.   Difference: Δ = E − 1, so Δaₙ = aₙ₊₁ − aₙ.

Example: aₙ₊₂ − 5aₙ₊₁ + 6aₙ = f(n) → (E² − 5E + 6)aₙ = f(n), i.e. F(E)aₙ = f(n).

Particular solution: aₙ⁽ᵖ⁾ = [1/F(E)] f(n).

(1/F(E))·cⁿ = cⁿ / F(c)  , provided F(c) ≠ 0

Why? E(cⁿ) = c·cⁿ, so F(E) acts like multiplying by F(c).

If F(c) = 0 → resonance (failure case): multiply trial by n (or n² if root repeated…).

Solve aₙ₊₁ − 3aₙ = 2ⁿ

Homogeneous: aₙ₊₁ − 3aₙ = 0 ⇒ C·3ⁿ.

Try aₙ⁽ᵖ⁾ = A·2ⁿ: A·2ⁿ⁺¹ − 3A·2ⁿ = −A·2ⁿ = 2ⁿ ⇒ A = −1.

aₙ = C·3ⁿ − 2ⁿ

Resonance: aₙ₊₁ − 2aₙ = 2ⁿ⁺¹

Homogeneous: C·2ⁿ. Trial A·2ⁿ duplicates it → use A·n·2ⁿ.

A(n+1)2ⁿ⁺¹ − 2A·n·2ⁿ = 2A·2ⁿ = 2·2ⁿ ⇒ A = 1.

aₙ = C·2ⁿ + n·2ⁿ

Polynomial forcing: aₙ₊₁ − aₙ = n

Δaₙ = n. Since Δ[n(n−1)/2] = n, particular = n(n−1)/2. Homogeneous = C.

aₙ = C + n(n−1)/2

Useful: Δn = 1, Δ(n²) = 2n+1, Δ[n(n−1)/2] = n.

5. Generating Functions

G(x) = a₀ + a₁x + a₂x² + … = Σ aₙxⁿ

The coefficient of xⁿ in G(x) is aₙ. It turns recurrences into algebra.

Sequence aₙG(x)
1, 1, 1, 1, …1/(1−x)
1, c, c², c³, … (aₙ = cⁿ)1/(1−cx)
0, 1, 2, 3, … (aₙ = n)x/(1−x)²
0, 1, 4, 9, … (aₙ = n²)x(1+x)/(1−x)³
Fibonacci 0, 1, 1, 2, …x/(1−x−x²)

Algebra rules

  • Linearity: αG + βH generates αaₙ + βbₙ.
  • Product: coeff of xⁿ in G·H is Σₖ aₖbₙ₋ₖ (convolution).
  • Σₙ₌₁^∞ aₙxⁿ = G(x) − a₀.
  • Σₙ₌₁^∞ aₙ₋₁xⁿ = x·G(x).
  • Σₙ₌₀^∞ aₙ₊₁xⁿ = [G(x) − a₀]/x.

Solve aₙ = 2aₙ₋₁ + 1 (n≥1), a₀ = 0 using G(x)

Multiply by xⁿ, sum for n ≥ 1:

Left: G(x) − a₀ = G(x). Right: 2x·G(x) + x/(1−x).

G(x)(1 − 2x) = x/(1−x) ⇒ G(x) = x/[(1−x)(1−2x)] = 1/(1−2x) − 1/(1−x).

Expand: G(x) = Σ (2ⁿ − 1)xⁿ. aₙ = 2ⁿ − 1

Generating function of Fibonacci

G(x) − x = xG(x) + x²G(x) ⇒ G(x)(1 − x − x²) = x.

G(x) = x / (1 − x − x²)

For an explicit formula, factor 1−x−x² and use partial fractions.

UNIT III : Counting & Relations

Part A: counting (how many objects?). Part B: relations (which elements are linked, and what properties?).

1. Inclusion–Exclusion (PIE)

Adding set sizes counts overlaps twice. So add singles, subtract overlaps, add triple back…

|A ∪ B| = |A| + |B| − |A ∩ B|
60 students: 35 Maths, 28 Physics, 15 both

|M ∪ P| = 35 + 28 − 15 = 48 study at least one

The overlap A ∩ B is counted twice, so subtract it once.

Three sets

|A∪B∪C| = |A|+|B|+|C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C|

Why add the triple at the end? A point in all three sets is counted 3 times (singles), removed 3 times (pairs) = 0 times, so add it back once.

"Neither" and complements

Neither A nor B = |U| − |A ∪ B|

General PIE

|⋃Aᵢ| = Σ|Aᵢ| − Σ|Aᵢ∩Aⱼ| + Σ|Aᵢ∩Aⱼ∩Aₖ| − … + (−1)ⁿ⁻¹|A₁∩…∩Aₙ|

Use PIE for surveys, divisibility counts, "at least one" problems. Always state what each set means before substituting.

3. Generalized Pigeonhole

n objects in k boxes ⟹ some box has ≥ ⌈n/k⌉ objects

⌊x⌋ = floor (round down); ⌈x⌉ = ceiling (round up). ⌈3.2⌉=4, ⌊3.7⌋=3, ⌈4⌉=4, ⌈4.01⌉=5.

10 objects in 4 boxes ⇒ some box has ⌈10/4⌉ = 3

Min. people to guarantee 3 share a birth month

Avoid it: at most 2 per month = 2×12 = 24. The 25th forces 3. 25 people

101 balls, 10 boxes

⌈101/10⌉ = ⌈10.1⌉ = 11 balls in some box

To guarantee r objects in one of k boxes: N = (r − 1)k + 1

Reason: with only (r−1)k objects every box could hold r−1. One more forces r.

4. Relations & Basic Properties

A relation R from A to B is any subset of A × B. If (a,b) ∈ R we write aRb. A relation on A is a subset of A×A.

A × B = {(a,b) : a∈A, b∈B}  ;   |A×B| = mn

Number of relations from A to B = 2^(mn). On an n-element set: 2^(n²).

A = {1,2,3,4}, aRb iff a divides b

R = {(1,1),(1,2),(1,3),(1,4),(2,2),(2,4),(3,3),(4,4)}

Six Properties of Relations

PropertyDefinitionGraph / matrix idea
Reflexive(a,a) ∈ R for all aloop at every vertex; diagonal all 1
Irreflexive(a,a) ∉ R for all ano loops; diagonal all 0
SymmetricaRb ⇒ bRaevery arrow has a reverse; M = Mᵀ
AntisymmetricaRb and bRa ⇒ a = bno two-way arrows between distinct vertices

Do NOT confuse

Symmetric: reverse pairs required. Antisymmetric: reverse pairs between distinct elements forbidden. Asymmetric: reverse forbidden and loops forbidden. A relation can be both symmetric and antisymmetric (e.g. equality).

One counterexample disproves a property. To prove it, check all cases or use a structural argument.

Test R = {(1,1),(2,2),(3,3),(1,2),(2,1)} on {1,2,3}

Reflexive: yes (all diagonal pairs).

Symmetric: yes ((1,2) & (2,1) together).

Transitive: yes (2-step paths among 1,2 return to 1 or 2, all present).

Antisymmetric: no ((1,2) and (2,1) both present, 1≠2).

Reflexive, symmetric, transitive; not antisymmetric

Digraph of (1,1),(1,2),(2,3),(1,3): a loop = pair (a,a)

5. Combining & Composing Relations

R⁻¹{(b,a) : (a,b) ∈ R} — reverse every pair

Composition S ∘ R (apply R first, then S)

S∘R = { (a,c) : ∃b with (a,b)∈R and (b,c)∈S }
R = {(1,2),(2,3)}, S = {(2,4),(3,5)}

1→2 (R) then 2→4 (S) gives (1,4). 2→3 (R) then 3→5 (S) gives (2,5).

S∘R = {(1,4),(2,5)}

Notation Check

Some books reverse the order of ∘. In exams, follow your instructor's definition. Here S∘R = "R first, then S".

Powers of a relation

R¹ = R, Rⁿ = Rⁿ⁻¹ ∘ R. (a,b) ∈ Rⁿ iff there is a path of length n from a to b.

R is transitive ⟺ R² ⊆ R (and then Rⁿ ⊆ R for all n).

6. Matrix Representation

For A = {a₁,…,aₙ}: MR is an n×n 0-1 matrix with mᵢⱼ = 1 iff (aᵢ,aⱼ) ∈ R. Keep the same order for rows and columns.

A = {1,2,3}, R = {(1,1),(1,2),(2,3)}

Row 1 = [1,1,0], Row 2 = [0,0,1], Row 3 = [0,0,0]. M = [[1,1,0],[0,0,1],[0,0,0]]

PropertyMatrix test
Reflexiveall diagonal entries = 1
Irreflexiveall diagonal entries = 0
SymmetricM = Mᵀ
Antisymmetricfor i≠j, mᵢⱼ and mⱼᵢ not both 1
TransitiveBoolean product M⊙M has no 1 where M has 0 (M² ≤ M)

Union / intersection → elementwise OR / AND. Composition → Boolean matrix multiplication (AND for products, OR for sums), not ordinary multiplication.

7. Equivalence Relations

Equivalence = Reflexive + Symmetric + Transitive
  • Equality on any set.
  • Same parity on integers (classes: evens, odds).
  • Congruence mod m: a ≡ b (mod m) iff m | (a − b).
Congruence mod m is an equivalence relation

Reflexive: a−a = 0, and m | 0.

Symmetric: a−b = km ⇒ b−a = (−k)m.

Transitive: a−b = km, b−c = ℓm ⇒ a−c = (k+ℓ)m. ∎

22

Equivalence classes & partitions

[a] = { x ∈ A : x R a }
  • Classes are non-empty; any two are identical or disjoint; their union is A.
  • So an equivalence relation partitions the set. Conversely, every partition gives an equivalence relation.
Classes modulo 3

[0] = {…,−6,−3,0,3,6,…}   [1] = {…,−5,−2,1,4,7,…}   [2] = {…,−4,−1,2,5,8,…}

8. Partial & Total Orders

Partial order = Reflexive + Antisymmetric + Transitive

A set with a partial order is a poset (A, ≼). Elements a, b are comparable if a≼b or b≼a; otherwise incomparable.

Total order = partial order where every pair is comparable.

Chain = subset with all pairs comparable. Antichain = subset of pairwise incomparable elements.

Domain Warning

Divisibility is a partial order on positive integers. On all integers antisymmetry fails: 2 | −2 and −2 | 2 but 2 ≠ −2. The MCQ bank says "integers" but intends positive integers. Follow your exam's stated domain.

9. Hasse Diagrams

A simplified drawing of a finite poset: smaller elements lower, larger higher. Draw an edge a—b only if b covers a (a ≺ b with no c, a ≺ c ≺ b).

  1. List elements and the order relation.
  2. Remove self-loops (reflexivity understood).
  3. Remove transitive edges — keep cover relations only.
  4. Minimal elements at bottom, maximal at top; join cover pairs by lines (no arrows).

Bounds, Meet & Join

Lower bound: below every element of S. Upper bound: above every element of S.

Meet (a ∧ b) = greatest lower bound (GLB). Join (a ∨ b) = least upper bound (LUB).

In {1,2,3,6} under divisibility

2 ∧ 3 = 1 (gcd)    2 ∨ 3 = 6 (lcm). Also 2 and 3 are incomparable.

10. Lattices & Sublattices

Lattice: for EVERY pair a, b, both a ∧ b and a ∨ b exist

In the power set P(S) under ⊆:  A ∧ B = A ∩ B,  A ∨ B = A ∪ B.

P({a,b}) is a lattice

Elements: ∅, {a}, {b}, {a,b}. Intersection = greatest common subset; union = least common superset.

{a} ∧ {b} = ∅ and {a} ∨ {b} = {a,b}. Lattice ✓

Sublattice: non-empty subset L′ of a lattice L that is closed under the inherited meet and join: a,b ∈ L′ ⇒ a∧b ∈ L′ and a∨b ∈ L′.

L′ = {∅, {a}, {a,b}} in P({a,b})

All pairwise intersections and unions stay in {∅, {a}, {a,b}}. It is a sublattice

Fast Sublattice Test

Take every pair, compute meet & join in the original lattice. If any result falls outside the subset → not a sublattice. Being a subset alone is not enough.

★ Final Rapid Revision ★

Read this the night before the midterm. It's a checklist, not a replacement for the derivations.

Unit I

  • p→q false only for p=T, q=F; p→q ≡ ¬p ∨ q.
  • Contrapositive ≡ original; converse & inverse are not.
  • De Morgan: negate each part, switch ∧ ↔ ∨.
  • Quantifier negation: ¬∀ = ∃¬, ¬∃ = ∀¬ (work from outside inward).
  • P↔Q: prove both P→Q and Q→P.
  • Direct: assume P → Q. Contrapositive: assume ¬Q → ¬P. Contradiction: assume ¬S → impossibility.
  • One counterexample kills a universal claim; examples never prove one.

Unit II

  • Initial conditions are part of the solution; fix n=0 vs n=1.
  • Try aₙ = rⁿ → characteristic equation.
  • Distinct roots → ΣCᵢrᵢⁿ; repeated root (mult. m) → rⁿ × polynomial of degree m−1.
  • Non-homogeneous = complementary + particular.
  • Forcing cⁿ: compute F(c); if F(c)=0 multiply trial by n (or n^mult.).
  • G(x) = Σaₙxⁿ; know 1/(1−x), 1/(1−cx), x/(1−x)² and shift identities.

Unit III

  • PIE: 2 sets add − overlap; 3 sets singles − pairs + triple.
  • Pigeonhole: some box ≥ ⌈n/k⌉; to guarantee r need (r−1)k+1.
  • Equivalence = R+S+T; Partial order = R+A+T; Total order adds comparability.
  • Matrix mᵢⱼ=1 iff (aᵢ,aⱼ)∈R; symmetry ⇔ M=Mᵀ.
  • S∘R = R first, then S.
  • Hasse: remove loops & transitive edges.
  • Lattice: every pair has meet and join. Sublattice: closed under both.

Top 10 Exam-Writing Habits

  1. Define symbols and the domain before starting a proof or counting problem.
  2. Write the formula first, then substitute numbers.
  3. In PIE, label each set and show the overlap term.
  4. In pigeonhole, clearly name the objects and the boxes.
  5. For relation properties, quote the exact definition; give a counterexample if it fails.
  6. In recurrences, state initial conditions before the closed form.
  7. Record root multiplicities; never skip the repeated-root rule.
  8. For generating functions, start sums at the right index and separate omitted initial terms.
  9. For Hasse diagrams, justify each edge as a cover relation — no transitive edges.
  10. Finally, substitute your answer back or do a quick sanity check.
